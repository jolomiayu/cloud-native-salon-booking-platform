# Cloud-Native Salon Booking Platform

A cloud-native web application deployed on Amazon EKS using Docker and Kubernetes.

## Project Overview

This project demonstrates how to build, containerize, and deploy a web application on AWS using modern DevOps practices.

## Features

- Responsive Salon Landing Page
- Dockerized Application
- Amazon Elastic Container Registry (ECR)
- Amazon Elastic Kubernetes Service (EKS)
- Kubernetes Deployment
- Kubernetes LoadBalancer Service

## Technology Stack
